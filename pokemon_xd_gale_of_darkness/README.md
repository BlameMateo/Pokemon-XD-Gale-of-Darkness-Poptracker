# Pokemon XD: Gale of Darkness PopTracker Pack

This is a Pokemon XD: Gale of Darkness tracker package for PopTracker. This tracker supports the Archipelago version of the Randomizer.

## Installation

Just download the latest release and put it in your packs folder.

## Bugs & Feedback

Feel free to post any issues you find on Github, or ask any questions in the Pokemon XD: Gale of Darkness thread on the Archipelago Discord!
